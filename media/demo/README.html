这是已运行软件的隔离Chrome浏览器录屏剪辑，与另外8条MiniMax AI产品概念片分开交付。常驻标签为「真实软件浏览器录屏 · 合成数据 · 设备模拟 · 离线规则」。没有硬件实测、真实业务数据或联网模型运行声明。

采用2026-09-06 01:50:09（上海时间）完成的最新成功QA员工/企业录制，与同次14项全通过的报告快照及截图时间一致。排除所有更早录制，包括01:49:20的一秒失败录制。员工15秒源与企业4.48秒源均为1440×960；成片放入1920×1080说明画布，不冒称原始浏览器录制为2K。

成片时间 画面与实际行为
00–06秒 员工收到会议提醒，本人批准后写入本地outbox，不外发
06–12秒 开启模拟隐私开关，模拟触摸被禁用
12–16秒 企业仅看到明确授权的业务汇总
16–21秒 员工撤销分享，已有共享数据被删除
21–28秒 同次成功验证截图定格：分享不足5人，企业汇总隐藏

前四段均是实际操作录像，标注0.5×慢放以便阅读。末段明确标注「同次成功验证截图定格」，原因是QA的移动布局检查会改变录屏视口；没有将静态截图伪装成连续操作。员工源8.72–8.84秒的fullPage截图瞬时视口变化已精确剪除，其他移动测试尾段也未使用。

所有选用片段都已进入认证后的工作台，未包含登录过程、令牌输入框或浏览器地址栏。原登录输入已核实type=password；制作脚本没有读取凭据文件、令牌或API Key。实际抽帧没有看到令牌明文。声轨为本机已有Tingting通过系统say生成的中文说明，未下载声音、未调用付费语音。

实际验收：精确28.000秒，1920×1080，25fps，H.264/AAC；实测音量 −16.19 LUFS、−1.50 dBTP；全部700帧执行灰色视口异常检查，0帧异常，见检查记录。另目视六帧联系图，确认常驻标签、分段说明、隐私开关与撤销结果可读。像素检查不是OCR或综合秘密检测；这里通过仅选认证后工作台区间、排除登录内容来避免令牌入镜。未声称人工听音或完整UI逐帧验收。

从项目根复现：

python3 media/demo/build_demo.py

脚本仅读取明确选定的既有录制和成功QA截图/报告，离线剪辑与本地配音，不启动浏览器、服务端口、用户全屏或其他应用。需要本机原始.local/qa-recording源文件及已安装ffmpeg/Pillow。成片展示的是该次成功QA快照，不替代此后软件改动的重新验证。大文件发布由主控统一处理。
