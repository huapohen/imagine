# 灵伴软件与固件验收资料

本会话只实现 `software/`、`firmware/`、`docs/software/`；Git、主板定型与发布由主控制器负责。未访问原始需求文件、任何 .env 或已有密钥，未读取或修改 `../active_agent`；本次代码为独立实现，无该项目代码来源。

## 运行与数据流

```sh
./software/start.sh
./software/test-integration.sh
```

Python 3.9+ 标准库 HTTP 服务 + SQLite，默认仅 `127.0.0.1:8765`。员工/企业使用启动时生成的不同 256-bit 随机 Bearer 令牌。终端输出的片段链接属于本地演示凭据，不能作为公开材料。页面清除 URL 片段，令牌只在内存中保存；不使用 localStorage、Cookie、第三方脚本或外部字体。重启清除旧令牌。SQLite 中仅存令牌 SHA-256。

```text
合成日程 / 任务事件 → 鉴权与权限 → 幂等事务 → SQLite 任务记忆
                                          ↓
                               每秒 worker 评估当前证据
                                 ↓ 新版本 / 新状态
                          专注静默与同规则同任务冷却
                                 ↓
                    带依据提醒 → 用户反馈 → 模拟灯光/小屏
                                 ↓
                   动作提案 → 人工批准 / 拒绝 → 审计
                                 ↓ 批准一次
                           本地 outbox（无发送器）
```

任务版本只在任务字段实际改变时增加。幂等键按员工隔离，相同键同内容返回原事件，不同内容返回 409。新幂等键但相同任务状态不会制造新提醒。冷却按员工、规则、任务计，默认 300 秒；新证据在冷却后仍有效才触发。专注期间所有主动提醒暂缓，结束后按当前状态重评；已解决的阻塞和已过期的会议不会补发。休息来自用户设置的计时器，无生理检测。提醒反馈支持有帮助、忽略、安静 10 分钟。API 名 snooze 保留兼容，但含义是暂停全部主动提醒 10 分钟，不承诺同一证据到期再通知；新证据在安静期后仍有效才触发。

审批采用 SQLite `BEGIN IMMEDIATE`，动作状态只能从 pending 转为 approved 或 rejected；outbox.action UNIQUE，重复相同决定返回 duplicate；终态改变返回 409。所有批准只持久化本地内容。没有邮件、聊天、支付或网络动作执行器。

## 权限与撤销

| 身份 | 可读 | 可写 | 不可访问 |
| --- | --- | --- | --- |
| 员工 | 自己的任务、提醒、动作、outbox、审计、设备 | 自己的事件、反馈、审批、授权及明确业务分享 | 他人数据、企业聚合 |
| 企业 | 本组织至少 5 位明确授权员工的业务聚合 | A2A 只读摘要任务的协议状态 | 个人工作台、事件、个人动作、录音、生理数据、员工评分 |
| 插件令牌 | manifest 授予的 tasks:read，且仅所属员工 | 白名单事件 / 灯光状态 | 审批、授权、分享、注册其他插件、A2A、隐私开关 |

企业结果只包含明确分享的 completed/blocked 整数。无按员工、群组任意过滤、排名、个人结果明细或历史聚合查询接口；人数仅显示分段。4 人及以下隐藏数值和精确人数。单次雇佣同意不构成共享授权。

撤销事务删除共享行，并删除本组织企业身份缓存的全部 A2A 摘要任务，避免历史 tasks/get 继续返回撤销前的聚合。重新授权不会恢复旧分享；必须再次明确提交。SQLite 开启 secure_delete，但本地磁盘/WAL、备份及浏览器已经看到的内容不等同于可取回；本原型不声称法证级擦除。企业 API 使用 no-store，页面每 2.5 秒刷新。>=5 仅满足本次演示门槛，不构成差分隐私，持续观察与外部知识仍可能推断变化，真实部署需固定发布窗口/队列和更严格隐私设计。

输入结构禁止音频、影像、生理字段、键盘记录及评分类型。自由任务文本是员工主动提供的合成内容，不执行语义分类；本原型不能保证自由文本中永远没有个人信息。企业从不读取自由任务文本。

## 插件

manifest 权限白名单：`events:write`、`tasks:read`、`hardware:write`。事件另需 `event_types` 白名单。manifest 登记不执行代码、不访问 URL、不安装依赖，不宣称 OS 沙箱。通过 `/api/plugins/token` 生成专用插件令牌。服务端从令牌绑定插件身份，省略或伪造 plugin_id 无法绕过权限；插件不应持有员工主令牌。修改 manifest 后下一次请求重新检查权限。
