# 创始人路演逐字稿

日期：2026-09-06。下文为可朗读正文；括号是舞台指令，不读出。3分钟版建议每分钟约230—260字，8分钟版每分钟约230—260字，含停顿/演示；必须实测排练，时间不是自动验证结果。当前没有实物交付/用户结果，演示只能使用明确标示的原型或交互模拟。

## 3分钟版

大家好，我们在做 Imagine，一个透明鼠标，也是一位主动式办公伙伴。

今天使用AI，很多时候还是我们先想起它、打开窗口、整理上下文，再提出问题。但工作里的遗漏，恰恰发生在我们没有想起来的时候：一条已经解除阻塞的回复，一个需要交接的任务，或者被打断后忘记的下一步。

Imagine想验证的是：AI能不能在有新证据、确实能帮忙时，主动迈出很小的一步。

（展示明确标注的交互模拟，停顿约十秒。）

你只授权它留意一个任务。新线索到来后，它不会立刻打断你，而是等待安静窗口，轻轻亮灯。你碰一下鼠标，看到提醒的理由和下一步。你可以接受、稍后或忽略；需要发送或修改外部内容时，先看清具体动作再批准。

我们先用成熟的有线鼠标底座，保证鼠标本身可靠。独立模块只负责灯、触摸和小屏，AI运行在电脑上。没有麦克风、摄像头和生理传感，也不承诺鼠标里运行大模型。

这是员工自己的伙伴。企业只能看到本人明确授权的业务结果，以及满足至少五人等防推断条件的汇总。我们不提供键鼠活跃度、情绪或个人绩效评分。

首发只做目标售价二百九十九元的核心版。在一千台规模假设下，完整制造成本一百零八元，扣除税预留、获客、退款、支持等变动费用后，每台约剩六十七元贡献。这些都是估算，必须由工厂报价和真实试用校正。

七天目标是五台可重复演示的样机。三十天只有在质量、合规和需求门槛通过后，才争取小批交付。我们先找二十名自愿用户，比较同样软件配普通通知和鼠标提示的差别。若硬件没有额外价值，就停止压库存。

我们希望获得的是有实际任务的设计伙伴和按里程碑投入的资源。先证明人愿意持续使用，再证明每一台交付值得做，最后才谈生态和规模。谢谢。

## 8分钟版

大家好，我们在做 Imagine，一个透明鼠标，也是一位主动式办公伙伴。我们希望它减少的是工作里的遗漏和反复切换，而不是增加一块需要照顾的屏幕。

先讲一个很小的场景。你正在准备交付，某个任务一直在等一份确认。确认已经到了，但它埋在另一个窗口里。你没有立即看到，项目又多等了半天。现有工具不是没有消息，而是消息太多；AI不是没有能力，而是常常需要你先意识到问题，再把上下文搬给它。

我们认为，可以先从一件可验证的小事开始：让用户授权AI持续留意一个任务，只在新的证据改变了下一步时介入。

（切换交互模拟，留约二十秒。）

这是一张个人任务卡。用户明确选择了要留意的任务和允许使用的数据。没有相关新证据时，伙伴保持安静。线索到了，它先合并上下文，等待安静窗口，再用灯光提醒。用户轻触一下，看到的是“为什么现在提醒你”，以及可以采取的下一步。用户可以接受、稍后、忽略，也可以一键暂停。需要对外发送或者修改内容时，系统先展示对象、内容和范围，由用户批准。

我们刻意把首期硬件做得简单。成熟的USB有线鼠标底座负责移动、按键和滚轮，独立的ESP32模块负责灯、触摸和小屏。AI在电脑本地agent运行，云模型只接收明确授权的必要内容。AI模块断开，鼠标仍应正常工作。这一条必须通过实机验证。

这意味着我们放弃一些很容易上台展示、却很难可靠交付的功能：第一期没有机器人运动、独立大模型算力、电池、摄像头和麦克风；也不做常驻录屏或锁屏后远程操作。触摸键是交互入口，我们不会把它宣传成已经具备独立安全芯片的不可绕过防护。

为什么还需要鼠标？因为它每天在手边，可能提供一种比屏幕弹窗更柔和、比手机提醒更直接的提示方式。透明结构让状态可见，也可能带来辨识度。但“可能”不是答案。高端鼠标用户未必愿意换设备，有线设计限制人群，灯光也可能烦人。

所以，我们会让二十名自愿测试者交叉体验：一周只有软件通知，一周加入灯光和触摸，保持内容相同。目标是提醒确认率提高至少十五个百分点，同时不增加主观打扰。七天仍启用比例目标为百分之六十，至少一半的人每周确认一次有帮助。我们还要在真实的二百九十九元价格下观察购买选择。这些是预先设定的门槛，不是现在已经获得的成绩。如果鼠标没有额外价值，我们就转向软件和可选桌面配件，而不是继续囤货。

这里有一个不能妥协的前提：这是员工自己的伙伴。企业采购并不意味着企业可以查看个人生活、私密聊天或所有操作。个人控制任务和分享，企业只获得逐项授权的业务结果，以及至少五人参与、经过小组和差分推断保护的汇总。人数阈值也不是匿名化的法律保证。我们不做个人效率排行榜、不做情绪推断、不做身体健康或键鼠活跃度评分。企业价值应当来自交接更清楚、阻塞更早被看见，而不是员工觉得被监视。

我们看了两个有意思的方向。Microduck官方展示了可训练的小型双足机器人，预售价三百九十九美元，税运另计；它启发我们把状态和人格做得可见，但十五个舵机显然不是首期低价鼠标应该承担的复杂度。Violoop官网展示独立算力、屏幕读取和实体审批，目前抓取到的是众筹前预约页面，不能当成爆卖证据。我们采用现有电脑算力，换取更轻的硬件成本和交付路径，也承认本地安装和系统权限会增加使用门槛。

商业上，我们只先制造一个核心SKU，目标售价二百九十九元。九十九和一百九十九元是低价方案探索，四百九十九和八百九十九元是套装与企业试点包设想。更高价格的桌面计算底座只属于生态概念，不收预售，也不计入收入。

在一千台规模的估算里，核心版完整制造成本是一百零八元。扣除税预留、渠道、退款、履约、质保、支持和四十五元获客成本后，每台贡献约六十六元五角。这不是净利润。按每月五万五千元固定支出，只卖核心版大约需要八百二十七台才能覆盖当月固定成本。前期小批成本可能达到一百七十元，那时每台贡献几乎消失，所以小批的目的必须是验证，不是做漂亮毛利。

我们的十个月模型更保守：假设有六十万元起始现金，十二万元一次投入，基准情景累计四千六百一十台，含税流水约一百五十八万元，仍累计亏损约二十九万元，期末现金约六万元。下行情景第十个月会出现现金缺口。上行情景也会被提前采购和企业账期压住现金。我们不把尚未发生的融资或订阅收入填进模型，资金不足时就缩减投入。

交付上，七天争取完成五台可重复演示的样机；三十天只有工程、质量、合规和用户门槛都通过，才争取五十到一百台受控交付。如果需要新开模、返板或者等待合规测试，就延后，不把日历当质量证明。

半年内的顺序是：先验证有用，再小批交付，再决定是否分批到一千台，之后才开放状态协议和一个配件。第十个月是检查点：有留存和贡献就继续经营，有合适产业合作再谈授权或交易；如果需求不成立，就有序完成退款、保修和数据义务。我们不会承诺下一轮融资，也不会承诺十个月退出。

今天希望找到的，是愿意用真实任务共同验证的个人和团队，以及理解分阶段投入的合作伙伴。Imagine是否值得存在，要由一个简单的问题回答：它主动提醒你的那一刻，你是否觉得，幸好它在。谢谢。
