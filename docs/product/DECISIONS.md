# 灵伴晶鼠：产品与交付决策

2026-09-06。这是本次工程方向与评审记录，不是已完成量产的声明。

## 先把一个办公动作做完整

同事交来新版本，灵伴发现它解除了你在等待的阻塞。它在专注时段结束后点亮鼠标里的一小段天空，你触摸查看依据，再决定采用交接草稿。事情没有变化时，它保持安静。用户能纠正它、撤销分享、关闭主动提醒；它不会因拟人化表达取得额外权限。

这条闭环将作为比赛现场演示主线：新证据 → 持久任务 → 时机判断 → 低打扰提示 → 本人确认 → 可追溯结果。用合成事件演示时全程标明合成数据，硬件未接入时明确设备模拟。

## 核心形态与首发选择

- 暂定品牌灵伴 LINGBAN，首款晶鼠 Crystal Mouse；正式出售前做商标与外观检索。
- 299元为1000台情景下的核心版目标含税零售价，需供应商报价和真实良率验证。首轮只验证这一核心硬件，避免五档同时备货。
- 当前5台工程样机沿用有线鼠标OEM总成，增加ESP32-S3开发板、交互载板、灯、触摸和小屏。它的单台成本、体积和两根USB线不等于将来量产BOM。
- 99元普通透明鼠标、199元无屏、499元外观/服务套装、899元企业配置包用于价格测试和后续选择；1499/3999元是扩展生态的研究方向。
- 内部城堡采用原创几何设计，可替换、可DIY。视觉版不用液体雪景：液体、密封、电子板和手汗环境会放大泄漏/返修风险。雪花先采用固定薄片与光学效果。

## 屏幕与传感器

首期使用0.96英寸SSD1306类单色OLED作为低成本状态屏候选，显示简短状态与图标，任务正文留在电脑。量产前核对模块针序、寿命、尺寸及供货；模拟文字显示不代表中文字体已完成固件移植。

彩色LCD可以承载更好的角色和动画，但增加供电、布线、成本与发热；墨水屏适合长时间静态状态，刷新和小尺寸选型限制它作为首发动画屏。高档位也不承诺“把手机所有器件塞进鼠标”。

首期触摸只做触发/舒适度互动，不输出疾病、压力、情绪、疲劳程度或员工表现。摄像头、麦克风、热成像、PPG等没有进入首发BOM；扩展模块需独立场景论证、可见开关和明确授权，不做隐蔽监听设备。

## 企业价值如何成立

企业可以观察经本人确认分享的交付、项目阻塞、协作流程和可复用工作模板。优秀员工可以自愿将方法整理为可审阅的技能卡，由同事选择采用；这能复制工作方法，不能复制一个人、也不能从生理信息推断能力。

团队汇总最少5名授权参与者，服务端隔离角色，固定时间窗口，抑制敏感小切片。这个人数门槛不是匿名化或合规证明；未实现差分保护的演示不能宣称不可重识别。管理者不得通过设备状态还原个人私密活动。

## 生态与协议

EVT-A唯一设备线协议为LB1（ASCII帧与CRC16），只传灯、状态、触摸和隐私信号；早期LBP/0.1 NDJSON草案已废弃。精确帧格式和共用向量见[串口规范](../software/serial-protocol.md)。MCP 2025-06-18负责工具调用，A2A 0.3.0负责其他Agent的任务协作；当前为明确列出的本地实现子集，未做官方SDK互操作或认证。插件权限先申请、逐项展示、可撤销，远程写入进入审批草稿与outbox。

个人数据、任务记忆和模型选择应能迁移。将来机器人可以实现同一套权限与任务合同，但运动控制、机械安全和实时性需独立工程，不能直接把鼠标软件称为通用机器人系统。

## 下周交给工厂什么

交给工厂的是工程讨论/打样候选资料：可编辑CAD、结构件STL/STEP（存在时）、图纸、接口定义、PCB源和真实检查结果、BOM、装配约束、RFQ与验收表。投板前由电子工程师复核；开模前先确认OEM总成尺寸、人体工学与公差。

比赛和投资人看到的实物状态由证据决定：数字模型、软件模拟、AI概念视频、实物样机、小批生产分别标记，不互相替代。
