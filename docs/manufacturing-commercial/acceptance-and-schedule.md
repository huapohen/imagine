7天验收：5台中的全部可完成鼠标基本功能、任务提醒/触摸查看、个人静音/暂停、模块断开后鼠标可用；连续8小时桌面运行无不可恢复故障；未授权事件不进入企业端，外部动作不自动执行。此测试不等于可靠性认证。

## D8—D30：条件成立才交付50—100台受控试产

D8—D10：选定候选工厂、DFM、10台EVT、冻结BOM候选和禁替代清单；实验室先判断适用标准与排期。D11—D14：解决高优缺陷、20人自愿试用开始、完成USB兼容/电气与外观初检；无合格物料不提前下大单。D15：G1评审；通过才签受控试产单，争取50—100台；付款、数量和期限需要具体合同。D16—D21：物料来料检查、首件确认、产测治具/程序验证、装配；并继续7日使用反馈。D22—D25：100%功能检查、规定抽样可靠性测试、返工复测。D26：G2评审核对合规判定、追溯、售后、个人数据和实际需求。D27—D30：只向已同意试产条件的客户分批发货；留售后备件与问题隔离空间。

若新增注塑模具、定制PCB返板、实验室排期、强制合规项、供料或人体工学任一未解决，30天节点改为工程评审，不强制发货。量产预测从实际EVT/PVT完成后重排，7天/30天不是对外交付保证。

## 三道放行门

| 门 | 放行条件 | 签字角色 |
|---|---|---|
| G0 原型→EVT | 独立鼠标链路、基本授权闭环、5台记录齐全、无安全关键缺陷 | 工程/产品 |
| G1 EVT→试产下单 | 10台EVT功能通过；DFM/BOM/合法USB身份明确；合规路径无未决强制障碍；20人测试已开始；资金能覆盖全单＋售后 | 工程/采购/财务 |
| G2 试产→交付 | 最终要求的测试/合规完成；100%出货功能合格；一次良率>=95%；无严重外观/电气/隐私缺陷；序列号可追溯；目标D7仍启用>=60%、至少半数确认有用；合同/退换/保修/数据说明齐备 | 质量/产品/交付负责人 |

这些是内部管理阈值而非统计质量保证。仅20人的留存不用于公开普适效果宣称；失败时先改产品，不放宽门槛掩盖问题。

## 验收矩阵（由工程把数值冻结进规格）

| 项 | 试产方法/数量 | 接受条件 |
|---|---|---|
| 鼠标基础功能 | 每台移动、左右键、滚轮、DPI功能如有；实机Win/macOS；Linux为扩展矩阵 | 无丢键/卡键/光学遮挡；登记实际系统版本 |
| USB链路 | 每台插拔10次；样本10台每台100次；挂起/恢复20次 | 枚举稳定；AI模块复位不拖垮鼠标；未通过hub方案退回双线 |
| 功耗/温升 | 样本5台测待机/最亮/通信/故障工况；8小时运行 | 不超USB协商供电及器件额定值；接触表面温度目标<=42℃（环境25℃），最终依合规实验室评估 |
| 灯/屏/触摸 | 每台显示测试图和全部状态、触摸100次；5台连续1000次 | 无坏点明显缺陷/失联；触摸只请求批准，不直接外部动作 |
| 透明壳外观 | 每台固定光照/距离检查并与签样比较 | 无锐边/裂纹/裸露导体；划痕、缩水、气泡按双方限度样定义 |
| 线材/应力释放 | 样本5台按双方确认弯折/拉力规范 | 无导体露出、接触不良；具体载荷由结构/实验室冻结 |
| 运输包装 | 3件包装样按适用运输测试方案跌落/振动 | 开箱功能正常、壳无裂、包装信息完整；不以自定跌落替代标准 |
| 8小时老化 | 全批或治具产能允许的完整计划；序列号记录 | 无死机/异常温升/显示故障，失败批隔离 |
| 数据边界 | 每固件/软件版本做未授权输入、撤回、暂停、删除、团队<5人、敏感字段注入 | 不对外发送、不产生个人绩效/生理推断；日志不含凭据 |
| EMC/ESD/安规/物质 | 最终结构与供电方案送有资质方，按适用规则 | 报告覆盖确切型号/版本，未完成必须标未完成并禁止需要该项的销售 |

100%功能检验与抽样破坏性试验分开。首批小批不照搬AQL表；如后续用GB/T 2828.1/ISO 2859-1，应书面确认批量、检验水平、AQL、Ac/Re和严重缺陷零接受规则。关键安全和隐私缺陷零容忍，任何一例触发批次隔离与根因评审。

## 采购与库存控制

建表字段：PO号、物料料号/版本、供应商、MOQ、单价含税口径、订购数、承诺日期、实到数、检验状态、付款节点、ECN、批次。第一单最多覆盖50—100台＋经批准的备件；未经需求门槛不提前下1000台。长交期屏/壳料优先双源评估，不能因断料随意换料；不预购无线芯片/电池/机器人电机。

缺陷返修先登记序列号、问题、固件和工位，再更换件和复测。返修设备本地不留用户任务资料；如果处理电脑agent问题，由用户导出脱敏诊断。退换政策、保修承诺与法定义务由销售地区实际规则审定，不以“试产”免除法定消费者权利。
